
# Data Dictionary

This document describes the main datasets, columns, data types, and business definitions used in the financial reporting dashboard.

## Data Sources

- Journal Entries
- Accounts
- Customers and Vendors
- Sales Invoices
- Purchase Invoices
- Payments
- Budget

## Data Quality

- Validate missing values.
- Check duplicate records.
- Reconcile financial balances.
- Validate transaction dates and currencies.
